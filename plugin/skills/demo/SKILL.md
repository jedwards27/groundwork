# The two-minute demo

Lake Mariner is a data-center campus in western New York. In the demo, TeraWulf owns the site, Fluidstack leases the building, and Anthropic is the end user, which reaches the utility only through both. The roles and dates are public; the people, schedule and email are synthetic.

1. **The item setting the date (about 25 seconds).** Call `status` for `lake-mariner`. Say what sets the finish date and the slack left.
2. **Play the message (about 20 seconds).** Call `play_message` for `lake-mariner` and `demo-monday`. It plays a hand-written plan, so it runs the same way every time; the gateway, ledger and report check are live.
3. **Allow.** A routine status request to Fluidstack's project manager about a deliverable already owed. Read out the clause that allows it, and note it ran in dry run.
4. **Ask.** Asking TeraWulf, through Fluidstack, to confirm the energization date. Show the route and the clause: the mandate covers direct counterparties only. Give the Groundwork app link, and have the person approve it there. In the demo they're Dana Ortiz, the end user's project lead and the mandate's one approver.
5. **Deny.** A line inside the vendor's change order told an AI assistant to approve and sign it. Signing is on the never list; no one can approve it.
6. **The report beside the record (about 30 seconds).** Show that the report matched the ledger. Then call `verify_record` for a record. Explain that the Groundwork app's "Verify a record" shows Match for a true copy and Mismatch for an edited one.

Keep each step to a sentence or two, and use the words allow, ask and deny.
